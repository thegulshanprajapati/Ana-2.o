Built and shipped My Ana AI, a full-stack AI platform designed to make AI more practical for everyday users and creators.

This project goes beyond a simple chatbot. I combined multiple workflows into one product:

- Context-aware AI chat with persistent history
- AI Code Studio for generating webpage code
- Image and document generation tools
- Multi-language support
- Admin knowledge-base management
- Community and creator workflows through AnaConnect

On the engineering side, I built it with Next.js 14, React, TypeScript, Tailwind CSS, and MongoDB, with support for both database-backed storage and local JSON fallback.

One of the most interesting parts was building the system so the app can use stored brain/context data, previous chat history, and user activity to produce more relevant responses.

This project helped me improve across product thinking, frontend experience, backend integration, and AI workflow design.

Still refining it, but I'm happy with how far it has come.

Feedback is welcome.
